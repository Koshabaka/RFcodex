# Пошаговая инструкция для новичков

## 1. Подготовка окружения
1. Установите Node.js LTS 20.x и npm (или настройте nvm).
2. Подготовьте офлайн-кэши:
   - npm-пакеты (`npm config set cache` указывающий на локальный каталог с tarball-архивами);
   - Pods для iOS (скопируйте каталог `ios/Pods`);
   - Gradle и Android SDK (скопируйте `.gradle/`, `gradle/`, `android/` каталоги с артефактами).
3. Убедитесь, что Xcode 17.5.1 и Android SDK доступны и не требуют загрузок.

## 2. Открытие проекта
1. Клонируйте репозиторий в офлайн-среду.
2. Выполните `npm install` — установка пройдет из локального кэша.
3. Откройте `RFcodex` в любимом редакторе (VS Code, WebStorm и т.д.).

## 3. Работа с данными
1. Поместите актуальные тексты кодексов в `data/raw/*.json` (см. пример файлов).
2. Запустите `npm run data:build` для генерации каталога и поискового индекса. Скрипт не обращается к сети.
3. Проверьте содержимое `data/dist/` — там должны появиться `catalog.json`, `index.json`, `index.meta.json`.

## 4. Сборка и запуск офлайн
### iOS
1. Убедитесь, что `ios/Pods` содержит все зависимости.
2. Выполните `npm run ios:offline`.
3. После сборки установите приложение в симулятор: `xcrun simctl install booted build/Debug-iphonesimulator/RFCodes.app` и запустите `xcrun simctl launch booted com.example.rfcodes`.

### Android
1. Убедитесь, что `android/gradle` и `.gradle` содержат необходимые артефакты.
2. Выполните `npm run android:offline`.
3. Установите APK: `adb install -r android/app/build/outputs/apk/debug/app-debug.apk`.

## 5. Проверка функциональности
1. Откройте приложение.
2. На главном экране найдите кодекс и перейдите к расширенному поиску.
3. Введите запрос — убедитесь, что результаты отображаются быстро, со сниппетами и подсветкой.
4. Перейдите в статью, проверьте хлебные крошки и форму быстрого перехода.
5. Откройте «Проверить обновления» и запустите проверку — появится сообщение из `UpdateProvider`.

## 6. Дополнительные сценарии
- Настройте тему и масштаб текста в «Настройках».
- Для варианта B (SQLite) подключите нативный модуль и поместите `rf_codes.db` в ресурсы платформ.
- Запустите `npm test`, чтобы убедиться в корректности токенизации и индекса.

Все шаги выполняются без сетевых запросов при условии заранее подготовленных артефактов.
