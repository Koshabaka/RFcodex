# RF Codes (React Native)

Кроссплатформенное офлайн-приложение справочника кодексов РФ для iOS и Android. Проект создан на React Native CLI (TypeScript, Hermes) и предназначен для сборки без сетевых подключений.

## Возможности
- Полный офлайн-доступ к текстам кодексов (ГК РФ, УК РФ в примере, легко расширяется).
- Локальный полнотекстовый поиск с обратным индексом и подсветкой совпадений.
- Фильтрация по конкретному кодексу.
- Просмотр статей с хлебными крошками и быстрым переходом.
- Экран проверки обновлений с выделенной абстракцией `UpdateProvider`.
- Настройки темы (системная/светлая/тёмная), масштаб текста, раздел «О приложении».
- Две стратегии хранения данных: JSON + собственный индекс (по умолчанию) и предсобранная SQLite-база.
- Без аналитики, пушей и сетевых зависимостей во время сборки.

## Системные требования
- macOS Sonoma 14.1 (Xcode 17.5.1) для iOS.
- Windows/macOS/Linux c Android Studio Iguana для Android.
- Node.js LTS 20.x, npm или yarn.
- Предзагруженные зависимости: pods, Gradle, Maven-репозитории, NPM-пакеты (офлайн-режим).

## Подготовка данных
1. Поместите тексты кодексов в `data/raw/*.json` согласно схеме:
   ```json
   {
     "metadata": {"id": "gk", "title": "Гражданский кодекс", ...},
     "chapters": [
       {"id": "part1", "number": "Часть I", "articles": [
         {"number": "1", "title": "...", "text": "...", "breadcrumbs": ["ГК РФ", "Часть I", "Глава 1"]}
       ]}
     ]
   }
   ```
2. Соберите каталог и индекс:
   ```bash
   npm install   # из локального npm-кэша
   npm run data:build
   ```
   Скрипт `scripts/build-data.ts` создаст `data/dist/catalog.json`, `index.json`, `index.meta.json`.

## Варианты хранения
### Вариант A — JSON + собственный индекс
- `src/data/storage/jsonDataSource.ts` читает `data/dist/catalog.json` и `index.json`.
- Индекс подгружается в рантайме без пересчёта.

### Вариант B — встроенная SQLite
- Реализуйте native-модуль `RFCodesDatabase` (iOS/Android) с методами `loadCatalog()` и `loadIndex()`.
- Поместите предсобранный файл `rf_codes.db` в ресурсы (`ios/RFCodes/Resources/Database/`, `android/app/src/main/res/raw/`).
- Класс `SqliteDataSource` использует модуль и автоматически откатывается к JSON при отсутствии реализации.

## Сборка и запуск офлайн
1. **iOS**
   ```bash
   npm run ios:offline
   ```
   Скрипт вызывает `xcodebuild` в офлайн-режиме. Для запуска на симуляторе используйте команды из вывода.

2. **Android**
   ```bash
   npm run android:offline
   ```
   Выполняется `./gradlew assembleDebug -PofflineMode=true`. После сборки установите APK на устройство через `adb`.

> Убедитесь, что все зависимости (Pods, Maven, NPM-пакеты) уже доступны локально. Проект не инициирует сетевых запросов во время сборки.

## Проверка функциональности
1. Запустите приложение на устройстве/симуляторе.
2. Откройте экран поиска, введите запрос (например, «равенства участников») — должны появиться результаты с подсветкой.
3. Откройте статью и воспользуйтесь хлебными крошками и быстрым переходом.
4. На экране «Проверить обновления» выполните ручную проверку; при отсутствии сети появится соответствующее сообщение.

## Тестирование
```bash
npm test
```
Тесты покрывают токенизацию, построение индекса и соответствие данных исходным файлам.

## Политика отсутствия телеметрии
- В проекте нет SDK аналитики, трекеров, пуш-уведомлений.
- Все запросы выполняются только локально; обновления проверяются вручную и отложены до реализации сервера.

## Лицензия
Проект предоставляется «как есть» в учебных целях. При добавлении реальных текстов кодексов соблюдайте требования законодательства РФ.
