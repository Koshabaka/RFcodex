# iOS офлайн-сборка

Каталоги `ios/Pods` и бинарные зависимости должны быть подготовлены заранее. В примерном проекте оставлен плейсхолдер, так как финальная интеграция зависит от конкретной среды.

## Основные шаги
1. Убедитесь, что все необходимые pods находятся в репозитории (в том числе `RCT-Folly`, `DoubleConversion`, Hermes и др.).
2. Откройте `RFCodes.xcworkspace` в Xcode 17.5.1.
3. Для офлайн-сборки используйте скрипт `npm run ios:offline`, который вызывает `xcodebuild` c настройками симулятора.
4. Предсобранную базу данных SQLite (вариант Б) поместите в каталог `ios/RFCodes/Resources/Database/rf_codes.db`.
